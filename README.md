# Pere Skyroom (Godot 3.6.3 Mono)

Небольшой 3D shooter-platformer, полностью написанный на C#.

## Управление

- `WASD` — движение
- `Space` — прыжок; в полёте набор высоты
- `Ctrl` — снижение в режиме полёта
- `Tab` — включить/выключить настраиваемое ускорение движения и прыжка
- `F` — включить/выключить режим полёта
- `B` — включить/выключить полноэкранный двухцветный blue-noise dithering
- `I` — поменять местами light и dark цвета dithering
- `R` — включить/выключить wireframe целей (отображается только вместе с dithering)
- `F2` — заново построить уровень и вернуть игрока в исходную позицию
- `F3` — показать/скрыть счётчик FPS
- `C` — включить/выключить две боковые камеры (−90° и +90°)
- `H` — скрыть/показать модель оружия (стрельба продолжает работать)
- `L` — скрыть/показать все экранные надписи и прицел
- `G` — включить/выключить accent dithering специальных объектов (только при включённом `B`)
- `V` — плавно включить/выключить панорамный угол обзора
- `ЛКМ` — выстрел
- `Esc` — освободить/захватить курсор
- `Alt+Enter` — переключить оконный и полноэкранный режим

Откройте `project.godot` в Godot 3.6.3 Mono и запустите сцену клавишей F6/F5.

Все элементы HUD находятся в сцене `Main.tscn` в узле `Main/HUD`. Их текст,
расположение, цвет и остальные свойства можно редактировать через Godot Editor.
Код `PlayerController` только получает ссылки на эти узлы и обновляет динамические значения.

Отдельный `Main/PlayerStatsHUD` также полностью описан в `Main.tscn` и доступен для
редактирования в Godot Editor. Пока он показывает только `BOOST: ON/OFF`. `PlayerStatsHUD`
находится на CanvasLayer `1200`, выше слоёв dithering и accent-эффектов, поэтому рисуется
после постобработки и не подвергается дизерингу. Переключатель обычного HUD (`L`) его не скрывает.

Начальные состояния визуальных переключателей задаются у корневого узла `Main` в Inspector:
dithering, инверсия палитры, боковые камеры, панорамный FOV, оружие, HUD, счётчик FPS,
wireframe и accent object dithering. При сбросе уровня через `F2` сохраняются текущие
состояния этих режимов. При полном новом запуске снова применяются значения Inspector.
Состояние режима ускорения `Tab` не относится к сохраняемым визуальным настройкам.
Его множители настраиваются у корневого узла `Main` в Inspector: параметр
`Speed Boost Movement Multiplier` применяется к ходьбе и полёту (по умолчанию `3.5`),
а `Speed Boost Jump Multiplier` — к прыжку (по умолчанию `1.0`).

Оружие отрисовывается отдельным прозрачным 3D viewport поверх сцены. Поэтому стены и
геометрия уровня не могут перекрыть оружие, но внутри самого weapon viewport продолжает
работать собственный depth-buffer для корректной отрисовки модели. Viewport использует
общий `World`: оружие находится на отдельном visual layer и получает освещение основной
сцены, включая `Sun`, тогда как игровые камеры этот слой не отображают.

Цвета постобработки настраиваются у корневого узла `Main` в Inspector через свойства
`Dither Dark Color` и `Dither Light Color`.
Если зелёная компонента исходного пикселя превышает `Dither Green Accent Threshold`
(по умолчанию `0.5`), dithering использует `AccentWireframeColor` вместо light color.
Для остальных пикселей алгоритм остаётся обычным двухцветным blue-noise dithering.
Инверсия палитры переключается клавишей `I` и по умолчанию выключена. Она меняет местами
только light/dark цвета dithering; accent-цвет остаётся неизменным.

Угол боковых камер задаётся в C# полем `SideCameraAngleDegrees` класса `Main`.
По умолчанию используется `90.0f`; камеры получают симметричные смещения `+угол` и `−угол`.

Плавный переход от прямого направления к боковым камерам включён по умолчанию через
`SmoothSideCameraTransitionEnabled`. Длительность задаётся полем
`SideCameraTransitionDurationSeconds` и по умолчанию равна `0.5f` секунды.

Панорамный угол обзора задаётся только в C# полем `PanoramicFovDegrees` класса `Main`
и по умолчанию равен `270.0f`. Переход туда и обратно задаётся полем
`PanoramicFovTransitionDurationSeconds` и по умолчанию занимает `0.5f` секунды.

Режим wireframe целей выключен по умолчанию и переключается клавишей `R`. При включённых
wireframe и dithering видимые части целей обводятся поверх результата постобработки.
Стены, платформы и другие физические объекты перекрывают accent-линии.
Толщина и accent-цвет задаются в `Main.cs` полями `AccentWireframeWidthPixels`
(по умолчанию `3.0f`) и `AccentWireframeColor` (по умолчанию `#00FF00`). Начальное
состояние задаётся полем `AccentWireframeEnabledByDefault`.

Режим object accent dithering выключен по умолчанию и задаётся полем
`AccentObjectDitherEnabledByDefault`. Он заменяет wireframe целей на blue-noise dithering,
используя `AccentWireframeColor` как light color и не изменяя остальные пиксели экрана.
Режим доступен только при включённом общем dithering (`B`) и автоматически выключается
вместе с ним.
